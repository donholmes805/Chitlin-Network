# Chitlin’ Network TV

Premium OTT / FAST-style cable TV streaming platform.

## Features
- **Cinematic UI**: High-fidelity design inspired by modern streaming ecosystems.
- **Live TV**: Lean-back broadcasting experience with scheduled programming.
- **On-Demand Catalog**: Browse and watch shows across multiple independent channels.
- **Channel Owner Portal**: Tools for creators to manage content, schedules, and analytics.
- **Admin Command Center**: Global network oversight and revenue management.
- **Secure Infrastructure**: Powered by Firebase Auth and Firestore.

## Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS v4
- **Backend**: Firebase (Auth, Firestore, Storage, App Hosting)
- **Video**: Provider-neutral architecture (HLS, MP4, YouTube, Vimeo, Mux, Cloudflare)

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`

## Deployment
Deployed via Firebase App Hosting. See `apphosting.yaml` for configuration details.
